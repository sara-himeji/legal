Privacy: what the bot stores

  • Server ID, the channel and role IDs you choose with /setchannel, and the anime list from /follow.
  • IDs of articles, episodes and chapters already posted, to avoid duplicates.
  • Operator settings such as an ad whitelist.

The bot does not store message content, direct messages or profiles of individual members. Technical error logs on the host can contain command names and error text.

Privacy: operator log

When the bot joins or leaves a server, the server name, ID, member count, and the owner's Discord name and ID are posted to a private log channel for the operator.

Privacy: other services

  • Discord delivers all messages and commands; its privacy policy applies.
  • AniList receives the search text or username you enter in lookup commands.
  • trace.moe receives the image link you give /trace.
  • Amazon receives you only if you click a buy button; Amazon's policy and cookies then apply.

News feeds are read without sending user data. Some of these services are outside the EU/EEA and process data under their own terms.

Privacy: legal basis, retention, rights

Running the bot you asked for is a legitimate interest (Art. 6(1)(f) GDPR). Server data is deleted automatically when the bot is removed from your server, or on request via the support server. You can request access, correction, deletion, restriction, portability and object to processing (Art. 15-21 GDPR) the same way. You may complain to a data protection authority; for Hesse this is the Hessischer Beauftragte für Datenschutz und Informationsfreiheit.

Privacy: these pages

These pages set no cookies, use no analytics, and load no external fonts or scripts. The web host records IP address and request time in server logs for security and operation (Art. 6(1)(f) GDPR).

The bot is meant for people old enough to use Discord and collects no age data. A parent or guardian can request deletion of a server's data via the support server.
